# Documentation

## Skills

- `skills/debugtoolSkill/` contains the runtime, debugTool, packaging, and Windows build guidance.
- `skills/algorithmStudio/` contains the Algorithm Studio teaching skills and references.
- `skills/projectSkills/` contains repository-wide validation skills.
- `algorithmStudio/` contains standalone Algorithm Studio rules and feedback notes.

## Project records

- `Devlog/` contains development notes and design records.
- `layerReadme.md` contains the layer-oriented project overview.
- `VISION.md` contains the long-term project vision.

The root `README.md` is the English project entry point and `READMEcn.md` is the Chinese entry point. Module-local `README.md` and `AGENTS.md` files remain beside the code they describe so their directory scope is preserved.
